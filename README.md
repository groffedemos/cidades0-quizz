# Cidades do Mundo - Quiz

Aplicação estática, em português, que testa conhecimentos sobre capitais de países ao redor do mundo. O quiz contém seis perguntas de escolha única, apresenta a pontuação ao término e permite reiniciar a atividade.

## Estrutura

```text
cidades0-quizz/
├── index.html  # Página única: estrutura, estilos e lógica do quiz
└── README.md   # Visão geral e estrutura do projeto
```

## Como executar

Abra `index.html` diretamente em um navegador. Não há dependências nem processo de compilação.

## Funcionamento

1. Selecione uma resposta para cada uma das seis perguntas.
2. Envie as respostas para ver a pontuação e um feedback.
3. Use **Tentar novamente** para limpar as escolhas e recomeçar.
